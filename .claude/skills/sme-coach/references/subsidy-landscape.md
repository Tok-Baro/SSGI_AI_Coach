# 정부·지자체 소상공인 지원사업 랜드스케이프

> 한국 소상공인이 활용할 수 있는 주요 지원사업 카테고리 + 매칭 가이드.
> 출처: 소상공인시장진흥공단 + 중소벤처기업부 + 서울시 + 지자체.

---

## 1. 지원사업 5대 카테고리

### 1.1 정책자금 (저금리 대출)
- **운용**: 소상공인진흥공단, 신용보증재단
- **대상**: 사업자등록 6개월 이상, 연매출 일정 이하
- **금액**: 1천만원 ~ 3억원
- **금리**: 1.4~3.0% (시중은행 대비 절반)
- **용도**: 운영자금, 시설자금
- **신청**: 소상공인24 (sbiz24.kr) 또는 신용보증재단 직접

### 1.2 컨설팅 (무료/저비용)
- **운용**: 소상공인진흥공단 → 자영업클리닉 / 1인 소상공인 멘토링
- **무료** (정부 지원)
- **분야**: 경영진단, 점포혁신, 마케팅, 회계
- **시간**: 5회 ~ 30시간
- **신청**: 소상공인진흥공단 홈페이지

### 1.3 교육 (무료)
- **운용**: 소상공인진흥공단 e러닝 + 오프라인 교육원
- **무료**
- **종류**: 디지털 마케팅, SNS 활용, 손익관리, 세무
- **수료증 발급** → 일부 지원사업 가점

### 1.4 시설·환경 개선 (보조금)
- **운용**: 자치구·시 자체 사업
- **금액**: 200만원 ~ 1천만원 (50~70% 보조)
- **용도**: 간판 교체, 인테리어 리뉴얼, 위생시설
- **예시**: 서울시 점포혁신 사업, 자치구 간판 교체 지원

### 1.5 디지털 전환 (보조금/바우처)
- **운용**: 중기부 + 지자체
- **금액**: 100만원 ~ 500만원
- **용도**: 키오스크, POS, 배달앱 광고비, SNS 마케팅 대행
- **예시**: 비대면 바우처, 디지털 전환 바우처

## 2. 자격 요건 핵심 기준

대부분의 지원사업이 다음 중 일부를 요구:

| 기준 | 대표값 | 비고 |
|---|---|---|
| 사업자등록 기간 | 6개월 ~ 3년 이상 | 사업 안정성 검증 |
| 연매출 한도 | 1억 ~ 30억원 이하 | 소상공인 정의 (도소매 30억, 서비스업 10억) |
| 상시 근로자 수 | 5인 미만 (제조업 10인) | 소상공인 정의 |
| 신용 등급 | NICE/KCB 6등급 이상 | 정책자금 대출 기준 |
| 세금 체납 | 없음 | 모든 지원사업 공통 |
| 폐업 이력 | 1년 이내 폐업 X | 일부 사업 제한 |

## 3. 신청 시 자주 놓치는 자격

1. **중복 수혜 제한**: 같은 카테고리 사업 동시 신청 불가
2. **업종 제한**: 도박·유흥·소비성 향락업 제외
3. **장소 요건**: 본인 명의 사업장 (전대 X)
4. **사업자 분류**: 간이과세자 vs 일반과세자 자격 다름
5. **세금 신고**: 부가세·종합소득세 체납 없음 필수

## 4. 사업계획서 핵심 포인트 (당선 패턴)

### 외식업 사업계획서 가점 요소
- 위치 분석 (유동인구 데이터 인용)
- 경쟁 분석 (반경 500m 내 동종 업체 수)
- 차별화 포인트 (메뉴·서비스·인테리어)
- 매출 목표 (월별 / 분기별)
- 자부담 비율 (보통 30~50%)

### 디지털 전환 사업계획서
- 현재 문제 (배달앱 의존, 단골 관리 부재)
- 도입 솔루션 (POS·키오스크·CRM)
- 도입 후 KPI (회전율 +20%, 단골 +30%)
- 정량 효과 (월 매출 +N만원)

## 5. 매칭 로직 — 사장님 데이터 → 추천 사업

```python
def recommend_subsidies(user):
    matches = []
    
    # 1. 정책자금 (대출)
    if user.business_age >= 6_months and user.credit_grade <= 6:
        matches.append("희망드림 정책자금")
    
    # 2. 디지털 전환 (배달앱·POS 도움)
    if user.industry in ["외식업", "소매업"]:
        matches.append("비대면 바우처")
    
    # 3. 점포혁신 (인테리어)
    if user.business_age >= 1_year and user.has_offline_store:
        matches.append("자치구 점포혁신 사업")
    
    # 4. 마케팅 (SNS·광고)
    if user.industry == "외식업" and user.sales < 1_000_man:
        matches.append("디지털 마케팅 바우처")
    
    # 5. 컨설팅
    if user.profile_completion < 80%:
        matches.append("자영업클리닉 (무료 컨설팅)")
    
    return matches
```

## 7. 손실 프레이밍 적용

대부분의 지원사업은 **신청 안 하면 영원히 못 받음** (회차당 한정 수량 + 마감일).

### 카피 패턴
- "이번 회차 안 신청하면 다음은 6개월 뒤예요"
- "올해 예산 다 쓰면 끝나는 사업이에요. 작년에는 9월에 마감됐어요"
- "사장님 자격 맞는데 신청 안 하면 [N]만원 그냥 지나가요"

## 8. 정직성 룰

- 자격 요건은 사업마다 다름 → 추천 시 "확인 필요" 단서
- 합격률은 사업마다 30~70% 다름 → 단정 금지
- 신청 절차에 시간 들어감 (사업계획서·증빙서류 준비) → 작업량 솔직히 명시

# 서울 상권 분석 가이드

> 서울시 25개 자치구 상권 유형 + 서울 열린데이터 지표 해석법.
> 출처: 서울시 우리마을가게 상권분석 + 행정동별 생활인구 데이터 + 상권변화지표.

---

## 1. 서울 상권 5대 유형

### 1.1 도심형 (CBD)
- **위치**: 광화문/시청/명동/종로/을지로
- **유동인구**: 직장인 중심 (평일 9~18시 피크)
- **특징**: 평일 점심 강세, 주말 약함, 객단가 중상위
- **유리한 업종**: 직장인 한식·일식, 카페, 편의점
- **불리한 업종**: 야간 주점 (직장인 회식만), 가족 단위 매장
- **임대료**: 가장 비쌈 (월세 1평당 30만원~)

### 1.2 부도심·역세권 (홍대/이태원/강남역/건대/신촌)
- **유동인구**: 20·30대 청년 + 외국인 (저녁·야간 강세)
- **특징**: 야간 매출 강함, 트렌드 빠르게 변동
- **유리한 업종**: 카페, 주점, 의류, 뷰티, 외식 트렌드
- **불리한 업종**: 일상 잡화, 시니어 타겟
- **임대료**: 비쌈 (월세 1평당 15~25만원)

### 1.3 주거형 (목동/잠실/상계/송파)
- **유동인구**: 가족 + 주부, 주말 강세
- **특징**: 안정적 단골 의존, 객단가 중간, 회전 느림
- **유리한 업종**: 분식·치킨·반찬가게, 미용실, 학원, 슈퍼
- **불리한 업종**: 야간 주점, 트렌드 의류
- **임대료**: 중간 (월세 1평당 8~15만원)

### 1.4 학군지·교육형 (대치/중계/목동/잠실)
- **유동인구**: 학생 + 학부모, 평일 오후 + 저녁 강세
- **특징**: 학원·교육 서비스 중심, 단가 높음
- **유리한 업종**: 학원, 분식, 카페(학부모), 문구
- **불리한 업종**: 술집, 성인 대상
- **임대료**: 중상위

### 1.5 관광·전통시장형 (북촌/익선동/광장시장/남대문)
- **유동인구**: 관광객 + 외국인, 주말 강세
- **특징**: 객단가 변동 큼, 시즌 영향 큼
- **유리한 업종**: 분식, 베이커리, 잡화·기념품
- **불리한 업종**: 동네 단골 의존 업종
- **임대료**: 관광지 수준 비쌈

## 2. 서울시 상권변화지표 4분류 해석

### 2.1 상권확장 (Growth)
- **의미**: 신규 진입 > 폐업, 신규 업체 영업기간 짧아짐
- **신호**: 시장 성장 중, 진입 기회 큼
- **사장님 메시지**: "새 가게 들어오는 속도가 빠른 동네예요. 차별화 안 하면 묻혀요"

### 2.2 다이나믹 (Dynamic)
- **의미**: 회전율 높음 (개업 + 폐업 둘 다 활발)
- **신호**: 도시재생/신규 개발 지역
- **사장님 메시지**: "들고남이 잦은 동네예요. 기회와 위험이 같이 와요"

### 2.3 정체 (Stagnant)
- **의미**: 신규·폐업 모두 적음, 영업기간 긴 가게가 많음
- **신호**: 시장 포화, 진입 어려움
- **사장님 메시지**: "이미 자리 잡은 가게들이 강한 동네예요. 우리만의 차별점이 꼭 필요해요"

### 2.4 축소 (Shrinking)
- **의미**: 폐업 > 신규 진입
- **신호**: 시장 위축, 고객 유지 집중 필요
- **사장님 메시지**: "동네 가게 수가 줄고 있어요. 신규 손님보다 단골 잡는 데 집중하세요"

---

## 3. HHI (시장집중도) 해석

> 허핀달-허쉬만 지수 = 각 업종 점유율 제곱의 합. 0~10000 범위.

| HHI | 의미 | 사장님 표현 |
|---|---|---|
| < 1500 | 분산된 시장 | "동네에 다양한 가게가 있어요. 차별화 기회 많아요" |
| 1500~2500 | 적당한 집중 | "특정 업종이 약간 우세하지만 진입 가능해요" |
| > 2500 | 집중된 시장 | "특정 업종이 동네를 점령했어요. 같은 업종이면 차별화 필수" |

### 외식업 적용 사례
- 강남역 근처: HHI ~3000 (한식 집중) → 한식집은 차별화 절대 필요
- 홍대 근처: HHI ~1500 (다양) → 신규 진입 유리

---

## 4. 직주비율 해석

> 직주비율 = 직장인구 / 상주인구. 1.0 기준.

| 직주비율 | 상권 성격 | 추천 전략 |
|---|---|---|
| > 2.0 | 강한 직장 상권 | 평일 점심 + 회식 메뉴 / 11~13시 + 18~20시 집중 |
| 1.0~2.0 | 혼합형 | 점심 직장인 + 저녁 가족 / 시간대별 다른 메뉴 |
| 0.5~1.0 | 주거 우세 | 주말 + 저녁 / 단골 시스템 + 가족 단위 |
| < 0.5 | 강한 주거 | 저녁 + 주말 / 배달 + 동네 단골 카톡 |

---

## 5. 집객력 점수 해석 (서울시 산출)

> 0~100점 척도. 지하철역/대형마트/학교/공원 등 가까울수록 높음.

| 점수 | 의미 | 권고 |
|---|---|---|
| 80+ | 매우 강함 | 워크인 손님 풍부, 임대료 비쌈 — 회전율 극대화 |
| 60~80 | 강함 | 균형 잡힌 입지, 마케팅 ROI 높음 |
| 40~60 | 중간 | 위치 한계, 온라인 채널로 보완 |
| < 40 | 약함 | 배달·온라인 의존도 ↑, 오프라인 단골 잡기 |

### 위치 약점 보완 전략 (집객력 < 40)
- 배달앱 입점 → 위치 무관 노출
- 인스타그램 → 검색 유입
- 카카오 채널 → 단골 락인
- 동네 협업 → 다른 가게 손님 끌어오기

---

## 6. 상권 생애주기 (서울시 분석)

### 도입기
- 신규 업체 비중 ↑, 영업기간 짧음
- 사장님 전략: 빠른 차별화 + 트렌드 선점

### 성장기
- 매출 증가, 다양한 업종 진입
- 사장님 전략: 단골 락인 + 정체성 구축

### 성숙기
- 매출 안정, 업종 포화
- 사장님 전략: 효율 + 단골 깊이 (객단가 ↑)

### 쇠퇴기
- 매출 감소, 폐업 증가
- 사장님 전략: 비용 절감 + 차별화 / 출구 전략

## 7. 자치구별 상권 특성 요약

| 자치구 | 강점 업종 | 특이사항 |
|---|---|---|
| 강남구 | 음식점, 의류, 미용, 학원 | 임대료 최상위, 객단가 ↑ |
| 서초구 | 학원, 카페, 한식 | 학군 + 직장 혼합 |
| 마포구 | 카페, 주점, 의류 | 홍대/연남/망원 트렌드 |
| 용산구 | 외국 음식, 카페 | 이태원·한남 외국인 |
| 종로구 | 한식, 카페 | 광화문·인사동 관광 + 직장 |
| 송파구 | 가족 외식, 마트, 학원 | 잠실·문정 주거 강세 |
| 성북구 | 분식, 학원, 한식 | 한성대·성신여대 학생 + 주거 |
| 동대문구 | 의류·패션, 외국 음식 | 동대문 패션상권 + 주거 |
| 영등포구 | 한식, 일식, 회식 | 여의도 직장 + 신길 주거 |

## 8. 데이터 인용 시 주의

서울 열린데이터는 **분기 단위** (3개월에 1번 갱신). 따라서:
- "이번 분기" 데이터는 1~3개월 지난 정보
- "이번 달" 표현은 부정확 → "이번 분기" 권장
- 실시간 변화는 카드 매출 / 배달앱 데이터 (별도 소스)

생활인구는 **일 단위 갱신**. 따라서:
- "어제 대비" 표현 가능
- 다만 시간대별이 아닌 일 평균이 기본

## 9. 외부 변수 점검 항목 (데이터에 없는 것)

진단 만들 때 GPT가 알 수 없는 외부 요인:
- 코로나·재난·재해
- 동네 행사·축제 (대학교 축제·구청 행사)
- 부동산 개발 (지하철 신설·재개발)
- 정책 변경 (최저임금·금리·임대차보호법)
- 경쟁업체 신규 오픈

→ 진단 카피에 이런 외부 요인이 있을 수 있음을 한 줄 정도 명시 (정직성).

# 업종별 손익 구조 + 손익분기점

> 한국 소상공인의 업종별 비용 구조와 손익분기 패턴.
> 출처: 외식산업연구원 + 통계청 도소매업조사 + 소상공인 컨설팅 실전 사례.

---

## 1. 외식업 평균 비용 구조

| 항목 | 비중 | 비고 |
|---|---|---|
| **식자재 (원가)** | 30~38% | 한식 35%, 카페 25%, 치킨 35% |
| **임대료 + 관리비** | 8~15% | CBD 15%, 주거 10%, 교외 5% |
| **인건비** | 20~30% | 본인 인건비 포함 |
| **공과금 (전기·가스)** | 3~5% | |
| **마케팅 (배달앱·광고)** | 5~12% | 배달앱 수수료 포함 |
| **기타 (포장·소모품)** | 3~5% | |
| **영업이익** | 10~25% | 잘 됐을 때 |

### 손익분기 매출 (BEP)
- 임대료 200만원 + 인건비 (사장+1명) 400만원 + 식자재 35% + 기타 10% = 고정비 약 600만원
- 매출 X 기준: 600 + 0.45X = X → X = 약 1,090만원/월

→ **외식업 손익분기 = 월 1,000만원 ~ 1,200만원**
   객단가 12,000원 기준: 일 평균 28~33명 손님

| 마케팅 | 3~8% |

### 손익분기

- BEP 매출: 약 760만원/월
- 객단가 6,000원 기준: 일 평균 42명

→ **카페 손익분기 = 월 700만원 ~ 900만원**

## 6. 세부 KPI별 임계값

### 외식업
| KPI | 안전 | 주의 | 위험 |
|---|---|---|---|
| 회전율 (홀) | 2회 이상 | 1.5~2 | < 1.5 |
| 객단가 (한식) | 1.5만원+ | 1.2~1.5만 | < 1.2만 |
| 배달 비중 | 30~60% | 60~80% | > 80% (수수료 압박) |
| 단골 비율 | > 50% | 30~50% | < 30% |
| 별점 (배민/네이버) | > 4.7 | 4.3~4.7 | < 4.3 |

### 카페
| KPI | 안전 | 주의 | 위험 |
|---|---|---|---|
| 일 평균 손님 | 60+ | 30~60 | < 30 |
| 객단가 | 7천원+ | 5~7천원 | < 5천원 |
| 평일/주말 매출 비율 | 40~60% | 30~40% | < 30% (직장인 미확보) |
| 단골 비중 | 60%+ | 40~60% | < 40% |

### 소매업
| KPI | 안전 | 주의 | 위험 |
|---|---|---|---|
| 평당 매출 | 200만+ | 100~200만 | < 100만 |
| 재고 회전 | 월 6+ | 4~6 | < 4 |
| 폐기율 | < 2% | 2~5% | > 5% |

### 미용실
| KPI | 안전 | 주의 | 위험 |
|---|---|---|---|
| 재방문율 | 70%+ | 50~70% | < 50% |
| 예약 비율 | 70%+ | 50~70% | < 50% |

## 7. 손익 진단 → 카피 변환

| 데이터 패턴 | 사장님 카피 |
|---|---|
| 매출 1000만원 / 임대료 250만원 (25%) | "임대료 비중이 25%로 높아요. 일반적으로 15% 이내가 안전권이라 매출을 더 끌어올리거나 메뉴 단가를 조정하셔야 해요" |
| 외식업 객단가 8천원 | "객단가 8천원이면 배달 수수료 빼고 마진이 빡빡해요. 사이드 메뉴 1개 추가하면 1만원선까지 자연스러워요" |
| 카페 일 평균 25명 | "하루 25명이면 BEP 미달이에요. 객단가 6천원 기준 매월 450만원 매출인데, 인건비+임대료+원가 합치면 ~~ 만원 부족해요" |
| 미용실 재방문율 38% | "10명 중 4명도 안 돌아와요. 시술 만족도가 떨어졌거나 단골 시스템이 비어있어요" |

## 8. 임대료 부담 진단 (모든 업종)

```
임대료 비중 = 월 임대료 / 월 매출

15% 이내 = 안전
15~20% = 주의 (마진 압박)
20%+ = 위험 (운영 지속 어려움)
```

→ 사장님 데이터에서 임대료 정보가 없으면 직접 묻거나 추정. 추정 못 하면 평당 매출 기준으로 우회 진단.

---

## 9. 정직성 룰 (AI 진단 시 필수)

- 손익 추정은 **업종 평균** 기반 (개별 가게 정확치 X)
- "약 ~만원" 식 추정 표기, 절대값 단정 금지
- 사장님 제공 데이터(매출/임대료/인건비)가 있으면 우선 사용
- 없으면 "일반적인 외식업 기준" 단서 명시

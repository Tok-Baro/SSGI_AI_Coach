## 2. 채널별 상세

### 2.1 배달의민족 (배민)
- **수수료**: 음식 가격의 6.8% + 결제 수수료 ~3%
- **광고비**: 울트라콜 8.8만원/월/지역 1건, 오픈리스트 전환당 8800원
- **핵심 ROI 요인**:
  - 가게 사진 ≥ 5장 → 클릭률 +28%
  - 메뉴 사진 ≥ 70% 등록 → 주문 +15%
  - 별점 4.7 이상 → 노출 우선순위 ↑
  - 리뷰 답글 100% → 신뢰도 ↑
- **언제 효과**: 외식업 전반, 특히 치킨·분식·한식
- **언제 비효과**: 객단가 < 8천원 (수수료 부담), 카페·디저트 (배달 적합도 낮음)

### 2.2 네이버 플레이스
- **검색 노출**: 네이버에 가게 이름 + 동네 검색 시 1~3위 노출 결정적
- **핵심 ROI 요인**:
  - 리뷰 50개 + 별점 4.5 = 상위 노출 자격
  - 리뷰 답글 비율 80%+ → 신뢰도
  - 사진 30장 이상 → 검색 가시성
  - 영수증 리뷰 (네이버 인증) > 일반 리뷰
- **광고**: 플레이스 광고 (지역 검색 키워드 입찰)
- **언제 효과**: 거의 모든 업종 (기본 인프라)

### 2.3 인스타그램
- **무료 노출**: 해시태그 + 위치 태그 + 릴스
- **광고**: 메타 광고 매니저, 1만원/일부터 가능
- **핵심 ROI 요인**:
  - 일관된 톤 (사진 색감 통일)
  - 주 3~5회 포스팅
  - 시그니처 메뉴 1~2개 시각화
  - 단골 댓글 → DM 1:1 응대
- **언제 효과**: 카페, 베이커리, 의류, 뷰티, 트렌디 외식
- **언제 비효과**: 분식·동네 슈퍼 (포스팅 부담 vs 효과 낮음)

### 2.4 카카오톡 채널
- **추가 비용**: 메시지 발송 건당 ~15원 (이미지 포함 시 ~20원)
- **핵심 ROI 요인**:
  - 친구 추가 시 쿠폰 발급 → 락인
  - 신메뉴 출시일 발송 → 즉시 매출 +25%
  - 주 1회 이내 발송 (스팸 방지)
- **언제 효과**: 단골 비중 높은 업종 (한식·미용·카페)
- **언제 비효과**: 원거리 손님 / 객단가 너무 낮은 업종

### 2.5 네이버 톡톡 / 카카오 채널
- **단골 1:1 응대**: 신상 입고, 예약 확인, 주문 후속
- **무료** (메시지 횟수 제한 있음)
- **언제 효과**: 의류·뷰티·미용실 (1:1 관계 중요)

### 2.6 오프라인 전단
- **비용**: 1,000장 인쇄 ~3만원 + 배포 ~2만원 = 5만원
- **반응율**: 평균 0.5~2%
- **언제 효과**: 신규 오픈 (인지도 0인 상태) / 동네 한정 이벤트
- **언제 비효과**: 이미 인지도 있는 가게 / 광고 면적 < 1km²

2. 네이버 플레이스

4. 카카오 채널 (스탬프 적립)

## 4. 예산별 추천 (월간)

### 예산 0원
- 네이버 플레이스 정비 (사진/리뷰 답글)
- 카카오 채널 친구 모으기
- 인스타그램 주 3회 포스팅
- **예상 효과**: 월 매출 +5~10% (3개월 누적)

### 예산 5만원
- 위 + 배민 울트라콜 1건 (8.8만원 → 일부 충당)
- **예상 효과**: 외식업 +15~25% (배민 효과)

### 예산 30만원
- 위 + 인스타 광고 (10만원) + 카카오 채널 발송 (단골 100명 × 5회 = 7500원) + 네이버 플레이스 광고 (10만원)
- **예상 효과**: 신규 손님 +30% / 단골 재방문 +20%

### 예산 100만원
- 위 + 유튜브 콘텐츠 1편 + 인스타 콜라보 (지역 인플루언서)
- **예상 효과**: 인지도 ↑ + 트래픽 폭발 가능 (가성비 가능성 + 위험)

## 5. 채널 운영 시 한국 소상공인 흔한 실수

1. **모든 채널 동시 시작**: 운영 부담 폭발 → 다 안 함. 채널 1개부터 단단하게.
2. **사진 품질 무시**: 스마트폰 자동 촬영 → 노출 효과 반토막. 라이트박스 5만원 투자 ROI 큼.
3. **리뷰 답글 안 함**: 별점 4.5+여도 답글 0%면 신뢰 신호 없음.
4. **단골 메시지 너무 자주**: 주 2회 이상 = 차단. 월 4회 이내.
5. **할인 남발**: 마진 갉아먹음. 신메뉴 + 시그니처에만 집중.

## 7. 한국식 마케팅 키워드 — 효과 검증된 표현

자주 쓰면 안 되는 (**식상**):
- "최고의", "최저가", "특가", "이벤트"

효과 검증된 (**손실 프레이밍 + 사회적 증거**):
- "이번 주만", "오늘 자정까지", "선착순 N명"
- "단골 N명이 추천한", "동네 1위 OOO"
- "사장님이 직접 만든", "20년 노하우"

신메뉴 출시 카피 템플릿:
> "[가게명] 신메뉴, [메뉴명] 나왔어요. 첫 주 단골 가격 [N% 할인]. 오늘 매장 오시면 사장님이 직접 추천해 드릴게요."

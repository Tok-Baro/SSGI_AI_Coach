# Human Tone — 사람처럼 한국어 카피 쓰기

## 언제 호출되는가

- "사람처럼 다듬어 줘"
- "이거 너무 AI 같아"
- "카피 써 줘" / "마케팅 글 써 줘"
- 한국어 PPT 슬라이드/PDF/이메일 카피 작성
- UI 마이크로카피 (버튼, 빈 화면, 에러 메시지)
- 푸시 알림 / 카카오 메시지

## 핵심 철학

> AI가 자동 생성하는 한국어는 **명사로 길게 잇고, 형용사로 부풀리고, 결론을 거창하게 마무리**하는 특징이 있다.
> 사람이 잘 쓴 한국어는 **짧고, 직설적이고, 구체 수치가 들어가고, 행동 유도가 명확**하다.

## 작업 순서

### Step 1 — 맥락 파악
다음 4가지 먼저 확정한다:

1. **누가 읽나** (소상공인 사장님 / 일반 소비자 / 투자자 / 동료 개발자)
2. **무슨 상황** (광고 / 공지 / 에러 / 빈 화면 / 완료)
3. **무엇을 하길 바라나** (행동 1개로 좁히기)
4. **분량** (헤드라인 12자 / 본문 50자/문장 / 단락 3문장)

### Step 2 — 프레임워크 선택

`references/frameworks.md`에서 상황에 맞는 1개 선택:

| 상황 | 프레임워크 |
|------|-----------|
| 처음 보는 잠재고객 | AIDA |
| 문제 알지만 행동 안 함 | **PAS** ← 기본 |
| 변화 보여주기 | BAB |
| 헤드라인 점검 | 4U |
| 긴 글/이메일 | PASTOR |
| 기술 → 일반인 | FAB |
| 한국 소상공인 | PAS + 사장님 화법 |

### Step 3 — 행동경제학 패턴 1~3개 결합

`references/behavioral-econ.md`에서 다음 6가지 중 **2~4개**만 결합 (다 넣으면 과해짐):

1. 손실회피 ("놓치고 있어요")
2. 사회적 증거 ("같은 동네 12명")
3. 희소성 ("D-3")
4. 권위 ("서울시 공식 데이터")
5. 호혜성 ("먼저 무료로")
6. 일관성 ("3단계 중 1단계")

### Step 4 — 한국 브랜드 코퍼스 참조

`references/corpus-korean-brands.md`에서 톤 참고:
- **토스 톤**: 미니멀, 3단 대구, 명사형 슬로건
- **당근 톤**: 동네 친구, 친근, 검색어 의인화
- **카카오뱅크 톤**: 1인칭 ("제가"), "나의 X" 시작
- **배민 톤**: 위트, 자조, 한국적 정서
- **야놀자 톤**: 카테고리 압축

### Step 5 — 톤 룰 적용

`references/tone-rules.md`의 검수 체크리스트:

- [ ] 한자 0개 (`grep -P '[\x{4E00}-\x{9FFF}]'` 0건) ← **하드룰**
- [ ] AI-ism 블랙리스트 0개 ("혁신적인", "당사", "고객님께서는" 등)
- [ ] 모든 문장 50자 이내 (헤드라인 12자 이내)
- [ ] 한 단락 3문장 이내
- [ ] "의" 한 문장에 3개 미만
- [ ] 능동형 우선
- [ ] 숫자 콤마 + 단위 정확
- [ ] 사장님 호칭 적절 (5문장에 1번)
- [ ] 구체적 다음 행동 (CTA)

## 빠른 참조 — 자주 쓰는 변환

### 약 → 강 변환표

| 약 (AI식) | 강 (사람식) |
|----------|------------|
| "추천해드립니다" | "찾아드릴게요" |
| "다양한 혜택이 제공됩니다" | "쿠폰 + 적립 + 할인" |
| "효율적으로 관리하세요" | "1분만 확인해 보세요" |
| "최적의 솔루션" | "딱 맞는 한 가지" |
| "고객님께서는" | "사장님" |
| "본 서비스는" | "AI 경영코치는" |

### 6요소 결합 헤드라인 템플릿

```
[호칭],
[사회적 증거] [수치] [손실 표현],
[희소성] [권위 출처] 기준 매칭.
[수치 효과] [CTA] →
```

**채우기 예시**:
```
사장님,
같은 동네 12명이 이미 받은 580만원을 놓치고 있어요.
D-3 마감, 서울시 공고 기반 매칭.
1분 만에 자격 확인하기 →
```

## 레퍼런스 인덱스

이 스킬은 작업 시 다음 파일들을 읽어들인다:

| 파일 | 내용 | 언제 |
|------|------|------|
| `references/frameworks.md` | AIDA, PAS, BAB, 4U, PASTOR, FAB | Step 2 |
| `references/behavioral-econ.md` | Cialdini 6원칙 + Kahneman 손실회피 외 | Step 3 |
| `references/corpus-korean-brands.md` | 토스/당근/카뱅/NOL 실수집 카피 | Step 4 |
| `references/tone-rules.md` | AI-ism 블랙리스트 + 검수 체크리스트 | Step 5 |

## 이 프로젝트 (SSGI_AI_Coach) 전용 룰

CLAUDE.md ADR과 충돌하지 않게:

- **ADR 001 (손실 프레이밍)**: 핵심 카피는 PAS 프레임워크
- **ADR 002 (k=10)**: 사회적 증거는 k≥10일 때만 노출
- **ADR 003 (하루 1액션)**: 카피도 한 번에 1개 행동만 요구
- **메모리 룰 (한자 금지)**: 출력 전 `grep -P '[\x{4E00}-\x{9FFF}]'` 0건 검증

## 안티패턴 — 이렇게 쓰면 즉시 다시 써라

### 안티패턴 1 — 형용사 폭격
> "혁신적이고 강력하며 효율적인 솔루션을 통해 다양한 비즈니스 측면에서 최적의 결과를 제공합니다"

→ 정보 0. 다 빼고 다시.

### 안티패턴 2 — 긴 명사구 사다리
> "사용자의 행동 패턴 분석을 통한 맞춤형 컨텐츠의 제공"

→ "사용자가 어떻게 쓰는지 보고, 맞춤 콘텐츠를 만들어요"

### 안티패턴 3 — 결론 거창
> "이 모든 것을 통해 여러분의 비즈니스가 한 단계 도약할 수 있을 것이라 확신합니다"

→ (다 빼라)

### 안티패턴 4 — 한자 사용
> "우리 회사는 [유동인구의 한자 표기] 데이터 분석으로 매출 [증가의 한자 표기]를 돕는다"

→ "유동인구 데이터로 매출 늘리는 걸 돕습니다" (메모리 하드룰)

### 안티패턴 5 — 영어 카멜케이스
> "고객님의 Engagement를 Boost하는 Solution"

→ "사장님 가게 단골을 늘리는 한 가지 방법"

## 빠른 사용 예시

**입력**: "사장님께 매일 한 개의 액션을 추천하는 서비스를 광고하는 카피 써 줘"

**출력 (이 스킬 적용)**:
```
사장님, 오늘 뭐부터 할지 막막하시죠?

AI 경영코치가 매일 아침 7시에
사장님 가게에 딱 맞는 액션 1개만 골라드려요.

서울시 공식 데이터 기반,
같은 동네 사장님 12명이 이미 시작.

지금 카카오로 15초 만에 시작하기 →
```

체크리스트 통과 확인:
- 한자 0건 ✓
- AI-ism 0건 ✓
- 최장 문장 28자 ✓
- 단락 3개, 각 1~3문장 ✓
- 손실회피 + 사회적 증거 + 희소성("15초") + 권위("서울시") ✓
- 사장님 호칭 1회 ✓
- CTA "시작하기" ✓

# 행동경제학 기반 설득 패턴

> 인간의 비합리적 의사결정 패턴을 활용한 설득 기법.
> 출처: Kahneman, Cialdini, Thaler, Ariely 등의 검증 연구.
> 한국어 카피 적용 예시는 소상공인/B2C 맥락 기준.

---

## 1. 손실회피 (Loss Aversion) — Kahneman & Tversky 1979

> 사람은 같은 크기의 이득보다 **손실을 약 2배 더 무겁게** 느낀다.

### 카피 변환 공식
- **이득 표현 → 손실 표현**으로 바꿔라.

| 약함 (이득) | 강함 (손실) |
|-----------|-----------|
| "월 50만원 더 벌 수 있어요" | "월 50만원을 놓치고 있어요" |
| "지원금 받으세요" | "신청 안 하면 내년까지 없어요" |
| "쿠폰을 받으세요" | "오늘 안 쓰면 사라져요" |
| "공고 매칭 4건" | "놓치는 공고 4건" |

### 한국 카피 적용 (이 프로젝트 ADR 001)
```
약: "사장님께 추천해 드려요"
강: "사장님이 모르고 놓치는 돈이 있어요"
```

## 2. 사회적 증거 (Social Proof) — Cialdini 1984

> 다른 사람들이 하는 행동은 그 자체로 증거가 된다.

### 강도별 패턴

| 강도 | 형태 | 예시 |
|------|------|------|
| 약 | 익명 다수 | "많은 분들이 사용 중" |
| 중 | 숫자 명시 | "1,247명이 신청 완료" |
| 강 | **유사군 명시** | "같은 동네 음식점 12명이 이미 신청" |
| 최강 | **실명 + 결과** | "○○○ 사장님 (반포동), 매출 30% 회복" |

### k-anonymity와 사회적 증거의 균형
> 이 프로젝트(SSGI_AI_Coach)는 ADR 002에서 k=10 이상에서만 사회적 증거 노출. 개인정보 보호 + 통계적 유의성.

### 카피 작성 룰
1. "**같은 X**" 앞에 붙이기 ("같은 동네", "같은 업종", "같은 매출 규모")
2. 절대 숫자 < 비율 ("12명" > "20%") — 사람은 숫자에 더 잘 반응
3. **시간 명시**: "이번 주에 12명" > "12명이 신청"

## 3. 희소성 (Scarcity) — Cialdini

> 부족하면 가치가 올라간다. 시간/수량/접근의 3가지 제약.

### 형태별

| 종류 | 예시 |
|------|------|
| **시간 제약** | "오늘 자정까지", "마감 D-3" |
| **수량 제약** | "선착순 100명", "5건 남음" |
| **접근 제약** | "사장님만 받을 수 있는" |

### 카운트다운의 강도
- "마감 임박" — 약 (모호)
- "이번 주까지" — 중 (확정)
- "D-3" — **강** (시각적, 매일 줄어듦)

### 윤리 룰
- **거짓 희소성 금지** — 매번 "오늘 자정까지" 표시되면 신뢰 붕괴
- 실제 마감일/재고와 동기화

### 한국 카피 적용
```
"우리 가게 조건에 맞는 지원금 4건
 — 평균 마감 D-7
 — 1건은 내일까지"
```

## 4. 기본설정 효과 (Default Effect) — Thaler 2003

> 사람은 **기본값을 그대로** 둔다. 옵트인보다 옵트아웃이 압도적.

### UI 카피에 적용
- **체크박스 미리 체크**: "월간 인사이트 리포트 받기 ✓"
- **"건너뛰기" vs "다음"**: "다음"을 시각적 강조
- **추천 옵션 라벨**: "(추천)", "(인기)" 표시

### 한국 카피 룰
1. 추천 옵션은 항상 첫번째 + "(추천)" 라벨
2. 거절 버튼은 텍스트만 ("나중에"), 추천은 컬러 버튼
3. 디폴트 미설정은 사용자 부담 → 기본값 항상 제공

## 5. 앵커링 (Anchoring) — Tversky & Kahneman

> 처음 본 숫자가 후속 판단의 기준점이 된다.

### 가격 카피 적용
- **할인 전 가격 먼저 노출**: "~~150,000원~~ → 99,000원"
- **상위 옵션 먼저**: 999만원 → 499만원 → 199만원 (Goldilocks 효과)
- **숫자 자릿수 늘리기**: "월 5만원" < "월 50,000원" (시각적 무게)

### 한국 카피 룰
1. 큰 숫자는 콤마 박기 ("580만원"보다 "5,800,000원" 시각 효과 큼)
2. 단위는 작게 ("5,800,000**원**")
3. 비교 대상이 있으면 옆에 옅게 ("월 99,000원 / 매월 ~~150,000원~~")

## 6. 호혜성 (Reciprocity) — Cialdini

> 받으면 갚아야 한다는 부채감.

### 카피 적용
- "**먼저** 무료로 X를 드리고 → 나중에 신청 권유"
- "사장님께 먼저 분석 리포트를 드릴게요. 마음에 들면 그때 결정해 주세요."

### 한국 카피 룰
1. 무엇을 줬는지 **명시** ("3페이지 분석 리포트", "지원금 매칭 결과")
2. 부담 줄이기 ("결정은 나중에", "그때 보시고")

---

## 7. 권위 (Authority) — Cialdini

> 전문가/공식 기관/숫자가 신뢰를 만든다.

### 강도

| 형태 | 예시 |
|------|------|
| 약 | "전문가 추천" |
| 중 | "OO연구소 인증" |
| 강 | "**서울시 공식 데이터** 기반" |
| 최강 | "한국은행 / 통계청 / 정부24 직접 연동" |

### 이 프로젝트 적용
- "서울 열린데이터광장 직접 연동"
- "정부24 사업자등록 검증"
- "행정안전부 인구 데이터"

### 한국 카피 룰
1. **공식 출처는 풀네임으로** ("서울시" 보다 "서울 열린데이터광장")
2. **검증 가능한 형태로 노출** ("출처: 서울시 VwsmTrdarStorQq")
3. 학술 권위는 일반인에게 약함 — 정부/대기업/공식 라이선스가 강함

---

## 8. 일관성 (Commitment & Consistency) — Cialdini

> 한번 시작한 행동은 일관되게 끝까지 가려는 욕구.

### 카피 적용
- **작은 약속부터**: "이메일만 알려주세요" → 이후 "정보 더 받아보실래요?"
- **단계 표시**: "1/3 완료", "마지막 단계!"
- **자기 선언 유도**: "나는 X 사장입니다" 체크박스 → 이후 X 카테고리 콘텐츠 수용도 ↑

### 이 프로젝트 적용 (온보딩)
```
1단계: 사업자등록번호 → 2단계: 가게 검색 → 3단계: 확인
(매 단계마다 진행률 바 + "거의 다 왔어요!")
```

## 9. 호감 (Liking) — Cialdini

> 좋아하는 사람/브랜드의 말을 더 잘 듣는다. 친밀감 구축.

### 한국 카피 적용
- **친근 호칭**: "사장님" / "님" / "여러분"
- **공감 도입**: "사장님도 이런 적 있으시죠?"
- **존댓말 + 직설**: "~해드릴게요" / "~이에요" (반말X, 너무 격식X)
- **유머**: 배민이 잘 쓰는 패턴 ("치킨은 살 안 쪄요. 살은 내가 쪄요")

---

## 10. 결정 피로 (Decision Fatigue) — Baumeister

> 선택지가 많을수록 결정 못 내림.

### 카피·UX 룰
1. **하루 1개 액션** (이 프로젝트 ADR 003) — 사용자에게 매일 단 하나만 제시
2. **최대 3개 옵션**: "A안 / B안 / 다른 옵션 보기"
3. **추천 1개 + 대안**: "이거 추천드려요. 다른 거 보실래요?"

---

## 11. 피크-엔드 룰 (Peak-End Rule) — Kahneman

> 경험 전체가 아니라 **가장 강한 순간 + 마지막 순간**으로 기억된다.

### 카피·UX 적용
- **결제 완료 → 임팩트 있는 메시지**: "사장님, 첫 지원금 신청 완료! 결과는 14일 내 알려드릴게요"
- **온보딩 끝**: 단순 "완료" 대신 "사장님께 맞는 지원금 4건 발견 — 580만원!"
- **마지막 화면을 가장 신경써라**

---

## 12. IKEA 효과 — Norton et al. 2012

> 자기가 직접 만든 것에 더 큰 가치를 부여.

### 카피 적용
- "사장님이 직접 입력한 정보로 매칭한 결과예요"
- "사장님이 만든 첫 쿠폰" (단순 "쿠폰"이 아니라)
- "사장님 가게 맞춤 분석"

## 13. 패턴 결합 — 이 프로젝트 카피 작성 체크리스트

소상공인 경영코치 카피 작성 시 다음 6가지가 동시에 들어가면 강함:

1. ✅ **손실 프레이밍** ("놓치는")
2. ✅ **사회적 증거** ("같은 동네 X명")
3. ✅ **희소성** ("D-3", "마감 임박")
4. ✅ **권위** ("서울시 공식 데이터")
5. ✅ **사장님 화법** ("사장님,", "~해 드릴게요")
6. ✅ **수치 구체화** ("580만원", "1분 만에")

### 6가지 모두 들어간 예시
```
사장님,
같은 동네 음식점 12명이 이미 받은 지원금 580만원,
사장님 가게도 받을 수 있어요.
서울시 공식 공고 기반 매칭, 마감까지 D-3.
1분 만에 자격 확인해 드릴게요. →
```

## 14. 안 쓰면 안 되는 윤리 룰

- **거짓말 금지** — "5초 만에" 라고 했으면 진짜 5초여야 함
- **공포 마케팅 자제** — 손실 프레이밍 ≠ 위협
- **취약 계층 표적 금지** — 노년·저소득층에게 강한 손실 프레이밍은 비윤리
- **거짓 희소성 금지** — "오늘 자정까지"가 매일 갱신되면 사기
- **사회적 증거 위조 금지** — "12명"이 진짜 12명이어야 함 (k=10 룰)

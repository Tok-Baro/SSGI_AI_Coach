# 톤 규칙 — "AI 같은" 글쓰기 피하기

> AI가 자동 생성한 텍스트의 특유한 어색함을 식별하고 사람이 쓴 것처럼 다듬는 규칙.
> 한국어 화자 기준.

---

## 1. AI-ism 블랙리스트 (즉시 삭제 대상)

> AI 텍스트에서 자주 등장하지만 사람은 거의 안 쓰는 표현.

### 1.1 과장된 형용사

| AI가 자주 씀 (X) | 사람 식 표현 (O) |
|----------------|----------------|
| "혁신적인" | "새로운" / "기존과 다른" |
| "획기적인" | (그냥 빼라) |
| "강력한" | "잘 작동하는" / "효과적인" |
| "최첨단" | "최근에 나온" |
| "고도화된" | (그냥 빼라) |
| "전문적인" | "잘 만든" |
| "효율적인" | "빠른" / "덜 걸리는" |
| "최적의" | "딱 맞는" |
| "포괄적인" | "전반적인" / (빼라) |
| "역동적인" | (대부분 빼도 됨) |

### 1.2 비어있는 표현

| AI 식 (X) | 사람 식 (O) |
|----------|------------|
| "여러 가지의" | "몇 가지" / "3가지" |
| "다양한 측면에서" | "이런저런 부분에서" |
| "보다 나은" | "더 나은" |
| "~에 있어서" | "~에서" |
| "~을 통해서" | "~으로" |
| "~함에 있어" | "~할 때" |
| "본 서비스는" | "이 서비스는" / "저희는" |
| "당사는" | "저희는" / 빼라 |
| "고객님께서는" | "사장님" / "여러분" |
| "지속적으로" | "계속" / "꾸준히" |

### 1.3 명사구 줄줄이 (NP-stack)

> AI는 명사를 의 / 의 / 의로 잇는다. 사람은 동사로 자른다.

**AI 식**:
> "사용자의 행동 패턴의 분석을 통한 맞춤형 콘텐츠의 제공"

**사람 식**:
> "사용자가 어떻게 쓰는지 보고, 맞춤 콘텐츠를 만들어요"

**룰**: "의"가 한 문장에 3번 이상 나오면 동사로 갈라라.

### 1.4 거창한 결론

| AI 식 (X) | 빼라 (O) |
|----------|---------|
| "결론적으로" | (그냥 본론만) |
| "요약하자면" | (꼭 필요할 때만) |
| "이를 통해 우리는 ~을 알 수 있습니다" | (사실만 말해라) |
| "다양한 분야에서 활용될 수 있는" | (빼라) |
| "여러분의 X에 도움이 되기를 바랍니다" | (낯간지러움) |

### 1.5 한자/외래어 남용 (이 프로젝트 절대 금지)

> 메모리 룰: 한자 0건 유지 (목차/유동인구/월/년/만원 등의 한자 표기 일체 금지).

## 2. 문장 길이 — 한국어 기준

### 룰
1. **한 문장 = 50자 이내** 권장 (헤드라인 12자 이내)
2. 한 단락 = 3문장 이내
3. **읽다가 숨이 차면** 자르기

### 길이 점검
- 60자 넘는 문장 → **무조건 자르기**
- 짧은 문장 + 긴 문장 교차 → 리듬

### 좋은 예
> 사장님, 지원금 580만원이 있어요.
> 같은 동네에서 12명이 이미 받았어요.
> 마감까지 D-3.
> 지금 1분만 확인해 보세요.

### 나쁜 예
> 사장님께서는 본인이 운영하시는 사업장과 관련하여 받으실 수 있는 지원금이 580만원 정도 책정되어 있는 상황이며, 이미 동일한 행정동에서 비슷한 업종을 운영하시는 12명의 사장님들이 신청을 완료하신 상태이고, 신청 마감까지 약 3일 정도가 남아있는 상황입니다.

→ AI식. 1문장 = 130자.

## 3. 어조 — 격식의 중간 지점

### 한국어 화법 스펙트럼

```
반말 ─── 친근체 ─── 해요체 ─── 합니다체 ─── 격식체
                    ↑
                여기 (대부분의 B2C)
```

### 해요체 룰
- 동사: "~해요" / "~예요" / "~죠"
- 명령: "~해 보세요" / "~해 주세요" (절대 명령형 X "~하라")
- 약속: "~해드릴게요" / "~알려드려요"
- 질문: "~인가요?" / "~죠?" / "~ㄹ까요?"

### 합니다체와 섞기
- 공식 통계나 출처: "서울시 자료입니다"
- 헤드라인: "받을 수 있어요" (해요체)
- 본문 사실: "12명이 이미 신청했습니다" (합니다체)
→ 강조 부분은 해요체, 사실 진술은 합니다체로 미세 조정

### 사장님 호칭 룰
1. 첫 등장: "사장님,"으로 운을 띄우기
2. 반복 시: "님" / "여러분" / 생략
3. 너무 자주 부르면 영업 같음 — 5문장에 1번 정도

## 4. 숫자 표기 — 한국식 시각 무게

### 룰
1. **만원 단위 콤마**: 580만원 / 5,800,000원 (둘 다 OK, 일관성만 유지)
2. **천 단위 콤마는 필수**: 1,247명 (1247명 X)
3. **단위는 작게**: "**5,800,000**원" — 숫자 굵게, 단위 보통
4. **분수보다 % > 1/3**
5. **시간 표기**: "1분 만에" / "3일 안에" / "오늘 안에"

### 시각 강조 우선순위
- 큰 숫자(절대값) > 비율 > 평균
- 예: "12명이 신청" > "20% 신청" > "평균 X명"

---

## 5. 동사 선택 — 능동 vs 수동

### 룰
- **능동 우선**: "도와드려요" > "도움을 드릴 수 있습니다"
- **주어 명시**: "AI 경영코치가 찾아드려요" > "찾아드립니다"
- **수동형 절대 금지 영역**: 
  - "~되어집니다" (이중 수동)
  - "~로 사료됩니다" (격식체)

### 좋은 동사 (한국어 카피의 황금)
- "찾아드려요" / "알려드려요" / "골라드려요"
- "놓치고 있어요" / "받을 수 있어요"
- "시작해 보세요" / "확인해 보세요"

### 약한 동사
- "제공합니다" → "드려요"
- "안내해드립니다" → "알려드릴게요"
- "활용 가능합니다" → "쓸 수 있어요"

## 6. 마이크로카피 — UI 짧은 텍스트

### 버튼 라벨 룰
- **명사 단독 X** ("쿠폰" → "쿠폰 만들기")
- **동사 종결**: "확인하기" / "다음" / "지금 시작"
- **3~7자 권장**

| 약함 | 강함 |
|------|------|
| "확인" | "지금 확인하기" |
| "신청" | "1분 만에 신청" |
| "OK" | "이 가게가 맞아요" |
| "취소" | "나중에 할게요" |

### Empty State (빈 화면) 룰
- 책망 X / 안내 O
- 구체적 다음 행동 제시
- 예: "아직 쿠폰이 없어요. 첫 쿠폰을 만들어 단골을 확보해 보세요"

### 에러 메시지 룰
- 코드 X / 사람 말 O
- 다음 행동 제시 ("다시 시도해 주세요" 등)
- 사장님 잘못이라 느끼게 하지 마라

| AI 식 (X) | 사람 식 (O) |
|----------|-----------|
| "Error 500: Internal Server Error" | "잠시 후 다시 시도해 주세요" |
| "유효하지 않은 입력입니다" | "10자리 숫자만 입력해 주세요" |
| "권한이 없습니다" | "로그인이 필요해요" |

## 7. 헤드라인 작성 룰

### 좋은 헤드라인 = 4U + 9~14자
- **U**seful: 쓸모 있나?
- **U**rgent: 지금?
- **U**nique: 다른 데서는?
- **U**ltra-specific: 구체적인가?

### 헤드라인 패턴 7가지

1. **수치 + 효과**: "1분 만에 580만원 찾기"
2. **부정 + 약속**: "사장님이 모르고 놓치는 돈"
3. **3단 대구**: "한도는 높게, 금리는 낮게, 부담은 적게"
4. **질문**: "이렇게 신청하셨어요?"
5. **명사형**: "지원금 자동 매칭"
6. **공간**: "동네 사장님만 보세요"
7. **결과 약속**: "월 50만원 회복까지 14일"

### 헤드라인 점검 체크리스트
- [ ] 12자 이내인가?
- [ ] 수치가 들어갔나?
- [ ] "지금"의 이유가 있나?
- [ ] 다른 데서 안 들어본 표현인가?

## 8. 단락 구성 — 모바일 가독성

### 룰
1. 한 단락 = 1~3문장
2. 단락 사이 빈 줄
3. **3줄 넘기면 잘라라**
4. 첫 줄에 핵심 주장
5. 마지막 줄에 행동 유도 (필요 시)

### 좋은 예 (모바일 최적)
> 사장님, 지원금 580만원이 있어요.
>
> 같은 동네 12명이 이미 받았어요.
> 마감까지 D-3.
>
> 지금 1분만 확인해 보세요. →

### 나쁜 예
> 사장님이 운영하시는 가게에 대한 지원금이 발견되었습니다. 총 580만원으로, 같은 행정동에서 12명의 사장님이 이미 신청을 완료한 상태이며, 마감일까지 약 3일이 남아있는 시급한 상황이니 확인이 필요합니다.

## 9. 검수 체크리스트 (글 완성 후 통과 기준)

작성 완료 후 다음을 통과해야 함:

- [ ] **한자 0개** (`grep -P '[\x{4E00}-\x{9FFF}]'` 0건) — 메모리 하드룰
- [ ] **AI-ism 블랙리스트 0개** — "혁신적", "당사", "여러분께서는" 등
- [ ] 모든 문장 50자 이내 (헤드라인 12자 이내)
- [ ] 한 단락 3문장 이내
- [ ] "의" 한 문장에 3개 이상 X
- [ ] 능동형 우선 (수동형은 의도적일 때만)
- [ ] 숫자에 콤마 + 단위 정확
- [ ] 사장님 호칭 적절 (5문장에 1번)
- [ ] 손실 프레이밍 1회 이상 (B2C 카피)
- [ ] 구체적 다음 행동 (CTA) 명시

## 10. 톤 페어링 (상황별 어조)

| 상황 | 어조 | 예시 |
|------|------|------|
| 기쁜 소식 | 가볍고 짧게 | "지원금 580만원, 받을 수 있어요!" |
| 손실 알림 | 단정 + 부드러운 직설 | "지금 신청 안 하면 내년까지 없어요" |
| 에러 | 사과 + 다음 행동 | "잠시 후 다시 시도해 주세요" |
| 빈 상태 | 격려 + 구체 | "첫 쿠폰을 만들어 단골을 확보해 보세요" |
| 완료 | 보상 + 다음 단계 | "신청 완료! 14일 내 결과 알려드릴게요" |
| 푸시 알림 | 강한 사회적 증거 | "같은 동네 12명이 신청 완료, 사장님은요?" |

# 카피라이팅 프레임워크

> 수십 년간 검증된 설득 글쓰기 구조. 각 프레임워크는 **언제 쓸지**가 다름.
> 한국어 적용 예시는 소상공인/B2C 맥락 기준으로 재구성.

---

## 1. AIDA — 가장 오래된 광고 공식 (1898, E. St. Elmo Lewis)

| 단계 | 의미 | 한국어 예시 |
|------|------|-----------|
| **A**ttention | 주목 끌기 | "사장님, 이거 모르고 계셨죠?" |
| **I**nterest | 흥미 유발 | "옆 가게는 이미 시작했어요" |
| **D**esire | 욕망 유도 | "월 100만원 더 받을 수 있는 길이 있어요" |
| **A**ction | 행동 유도 | "지금 1분만 확인해 보세요" |

**언제 쓸까**: 차가운 잠재고객 (처음 보는 사람) / 광고 카피 / 랜딩 hero

**약점**: 너무 잘 알려져서 식상하게 느껴질 수 있음. 후속 프레임워크들이 이를 보완.

### 한국 적용 예시 (소상공인 경영코치)
```
[A] 사장님이 모르고 놓치는 돈, 5,800,000원
[I] 같은 동네 음식점 12명이 이미 신청했어요
[D] 우리 가게 조건에 맞는 지원사업 4건이 매칭됐어요
[A] 지금 1분 만에 확인하기 →
```

## 2. PAS — 손실 프레이밍의 정석 (Problem-Agitate-Solution)

| 단계 | 의미 | 의도 |
|------|------|------|
| **P**roblem | 문제 제시 | "이 문제 있죠?" |
| **A**gitate | 불안 증폭 | "이대로 두면 더 커져요" |
| **S**olution | 해결 제시 | "이걸로 해결됩니다" |

**언제 쓸까**: 잠재고객이 문제를 인지하고 있지만 행동 안 할 때 / **손실 프레이밍** 

**왜 강력한가**: 손실회피(prospect theory) 기반 — 사람은 같은 크기의 이득보다 손실을 2배 더 무겁게 느낌.

### 한국 적용 예시
```
[P] 이번 달도 매출 전월 대비 8% 빠졌어요
[A] 같은 추세면 3개월 안에 운영비도 못 맞춰요
[S] 유동인구가 늘고 있는 화·목 저녁에 1+1 쿠폰을 노출하면 회복 가능
```

> **이 프로젝트(SSGI_AI_Coach)의 핵심 프레임워크**. CLAUDE.md에 ADR 001로 명시됨.

## 3. BAB — 변화 보여주기 (Before-After-Bridge)

| 단계 | 의미 |
|------|------|
| **B**efore | 지금 이 상태 (불편함) |
| **A**fter | 바뀐 상태 (이상적) |
| **B**ridge | 거기까지 가는 다리 (제품/서비스) |

**언제 쓸까**: 변화의 가치가 명확한 제품 / 다이어트, 학습, 도구

### 한국 적용 예시
```
[B] 지원사업 공고 매주 일일이 검색? 자격 일일이 확인?
[A] 우리 가게에 맞는 사업만 핀포인트로 알림
[B] AI 경영코치가 매일 1건씩 골라드려요
```

## 4. 4U — 헤드라인 강도 점검 (Useful, Urgent, Unique, Ultra-specific)

| 차원 | 질문 |
|------|------|
| **Useful** | 독자에게 쓸모 있나? |
| **Urgent** | 지금 봐야 할 이유 있나? |
| **Unique** | 다른 데서는 안 들리나? |
| **Ultra-specific** | 구체적인 수치/이름이 있나? |

**언제 쓸까**: 헤드라인·배너·푸시 알림 카피 작성 후 **체크리스트로**

### 평가 사례
- "지원금 신청하세요" → 0/4 (다 미충족)
- "사장님 가게 자격 맞는 지원금 4건, D-3 안에 신청 안 하면 내년까지 없어요" → 4/4 ✓

## 5. PASTOR — 장문 카피용 (Pain, Amplify, Story, Transformation, Offer, Response)

긴 광고 카피·랜딩 페이지·이메일 마케팅에서 사용.

| 단계 | 의미 | 한국어 예시 (간략) |
|------|------|------------------|
| Pain | 고통 | "월말마다 통장 잔고 보고 한숨..." |
| Amplify | 증폭 | "이대로면 보증금까지 까먹어요" |
| Story | 이야기 | "저희 고객 김 사장님은..." |
| Transformation | 변화 | "3개월 만에 매출 30% 회복" |
| Offer | 제안 | "AI 경영코치 무료 체험" |
| Response | 응답 유도 | "지금 카카오로 시작하기" |

**언제 쓸까**: 긴 형식이 필요한 메일·블로그·VSL(영상 광고)

---

## 6. FAB — 제품 설명용 (Feature-Advantage-Benefit)

> "**기능 → 강점 → 사용자 이득**"의 사다리.

| 단계 | 답하는 질문 | 예시 |
|------|------------|------|
| Feature | 무엇? | "RAG 기반 매칭 엔진" |
| Advantage | 그래서? | "공고 5만건 중 사장님 가게에 맞는 4건만 골라줌" |
| Benefit | 나에게? | "공고 검색 시간 주 5시간 → 0시간" |

**언제 쓸까**: 기술 스펙을 일반인에게 설명할 때.

> **함정**: Feature만 써놓고 Benefit이 없는 카피가 80% — 항상 "**그래서 나에게 뭐가 좋은데?**"까지 가야 함.

## 7. 5단 시나리오 — 로버트 콜리어식 (R. Collier)

1. **약속**: "이 글을 끝까지 읽으면 X를 알게 됩니다"
2. **그림 그리기**: 변화된 모습 묘사
3. **증명**: 데이터·후기·권위
4. **압박**: 안 하면 어떤 일이 일어나는지
5. **밀기**: "지금 클릭"

**언제 쓸까**: 영상 스크립트·세일즈 페이지 1편 통째로

---

## 8. 한국적 변형 — "사장님 화법" 프레임워크 (이 프로젝트 자체 정의)

소상공인을 대상으로 할 때 일반 카피 프레임워크에 다음 4가지를 덧입힌다:

1. **"~해 드릴게요" 약속체**: 명령형보다 부드러움 ("확인해 드릴게요" > "확인하라")
2. **"사장님" 호칭**: 거리 좁히되 존중 유지
3. **수치 앞 콤마**: "5,800,000원" — 한국인은 만/억 단위로 읽으니 백만 단위에서 콤마가 시각 도움
4. **"놓치고 있어요"**: 부정 분사 종결 — 이미 발생한 손실을 환기

### 결합 예시
```
사장님,
이번 달에 받을 수 있는 지원금 580만원이 있어요.
같은 동네 사장님 12명은 이미 신청 완료했고
마감까지 D-3 남았어요.
지금 1분만 확인해 드릴게요. →
```

(PAS + AIDA + 사장님 화법 결합)

## 9. 프레임워크 선택 가이드

| 상황 | 추천 |
|------|------|
| 처음 보는 광고 (cold) | AIDA |
| 문제 인지하지만 행동 안 함 | **PAS** ← 이 프로젝트 기본 |
| 변화 보여주고 싶음 | BAB |
| 헤드라인 점검 | 4U |
| 긴 글 / 이메일 / VSL | PASTOR |
| 기술 → 일반인 설명 | FAB |
| 한국 소상공인 대상 | PAS + 사장님 화법 |

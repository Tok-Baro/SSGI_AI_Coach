# 한국 VC / AC 생태계 — 2026 기준

> 한국 VC는 미국 VC와 화법·평가·의사결정이 다르다.
> "글로벌 톤"으로 한국 VC에 가면 거리감, "한국 톤"으로 미국 VC에 가면 ambition 부족 신호.

## 2. VC별 화법 차이 (실제 미팅 톤)

### 카카오벤처스 — "카카오와 어떻게 시너지?"
- 카카오톡·알림톡·카카오페이·카카오맵 중 1~2개 통합 명시 필수
- 사용자 화법: 사장님 / 소비자 친화 톤
- "카카오 채널 친구 N명" 같은 메트릭 좋아함
- 화법 예시: "이 기능이 카카오톡에 어떻게 녹나요?"

### 본엔젤스 — "한국에서 작게라도 PMF?"
- 트랙션 작아도 OK, **창업자 헌신** 우선
- "왜 이 문제를 본인이 푸는가" 스토리 중요
- 멘토링 강함 → 1년 안 보고 3년 보는 자세
- 화법 예시: "이거 5년 동안 할 자신 있어요?"

### 알토스벤처스 — "글로벌 가능?"
- 한국에서 토스·당근·우아한처럼 **카테고리 1등** 가능성
- 영문 IR 필수, LP들이 미국 중심
- 시장 글로벌화 가능성 강조
- 화법 예시: "이거 미국에서도 통할까요?"

### 매쉬업엔젤스 — "빠른 BEP?"
- 빠른 흑자 전환 가능성
- B2C 한국 시장 중심
- 실용적 / 빠른 GTM
- 화법 예시: "이거 한 달에 얼마 벌 수 있어요?"

### 슈미트 — "미국 LP에게 설명 가능?"
- 영문 IR 필수
- 글로벌 SaaS 메트릭 (NRR / Magic Number / Burn Multiple)
- 미국 비교 가능 카테고리 좋아함
- 화법 예시: "Y Combinator 어느 회사와 비슷한가요?"

### 신한벤처투자 — "핀테크 + 안정성"
- 신한금융 LP 시너지
- 규제 / 컴플라이언스 강함
- 큰 시장 + 단계적 성장
- 화법 예시: "이 사업 라이센스 필요한가요?"

### 한국투자파트너스 — "안정 + 다음 라운드"
- B2B / 헬스 / 안정 섹터 선호
- 다음 라운드 (Series A → B) 가능성
- 큰 LP들이 안정 운용 요구
- 화법 예시: "다음 라운드 투자자 누구 들어올 것 같아요?"

## 3. 한국형 IR 덱 vs 미국형 차이

| 차원 | 한국형 | 미국형 |
|---|---|---|
| 분량 | 15~20장 | 10~15장 |
| 톤 | 정중·정직·"가설" 라벨 | 도전적·확신 |
| TAM | bottom-up + 출처 | top-down + 비교 가능 |
| 트랙션 | 작아도 정량 + 정성 | 큰 숫자 + 차트 |
| 팀 | "이 문제와 연결" | LinkedIn + 이전 exit |
| 정부 | 지원사업·MOU 명시 | 거의 없음 |
| ESG | 정부 모드면 필수 | 거의 없음 |
| Ask | 명확 + 사용계획 | 명확 + 라운드 구조 |
| 폰트 | Pretendard / 맑은 고딕 | Inter / SF Pro |
| 색 | 정색 (검정·진한색) | 브랜드 색 강함 |
| 데모데이 후 | 1:1 미팅 정중 메일 | 후속 메일 즉각 |

→ 한국 VC에 미국 톤으로 가면 "건방진 신호". 미국 VC에 한국 톤으로 가면 "ambition 부족" 신호. 톤 매칭이 IR 덱의 절반.

## 4. AC → Pre-A → Series A 흐름 (한국 평균)

```
[Pre-Seed] 1~3억
  창업자 자본 + 친지 (Friends & Family)
  AC 입주 (스파크랩 / 퓨처플레이 / 카카오벤처스)
  ↓ (6~12개월)
[Seed] 3~10억
  엔젤 + 시드 VC (본엔젤스 / 카카오벤처스)
  데모데이 통과 → 1차 미팅
  ↓ (6~12개월)
[Pre-A] 5~20억
  TIPS R&D 5억 + 사업화 자금
  CVC 1~2개 (카카오벤처스 / KB / 신한)
  Lead VC 1개 + Follower 2~3개
  ↓ (12~18개월)
[Series A] 20~100억
  대형 VC (알토스 / 한투 / 소뱅)
  미국 LP 가능성
  ↓ (18~24개월)
[Series B] 100~300억
  성장 자본
  미국 / 일본 진출
```

→ Pre-Seed에서 Series A 자료 만들면 즉시 NO. 단계 매칭 절대 룰.

## 6. CVC vs 일반 VC 차이

### CVC (대기업 자회사)
- **장점**: 대기업 시너지 (유통·기술·고객 베이스)
- **단점**: 의사결정 느림 (3~6개월), 모회사 정치
- **화법**: 모회사와 어떻게 협력할지 명시 필수
- **예시**: 카카오벤처스 → 카카오톡 / D2SF → 네이버 / ZER01NE → 현대차

### 일반 VC
- **장점**: 의사결정 빠름 (1~3개월), 자율
- **단점**: 후속 시너지 부족
- **화법**: 시장 / 트랙션 / 팀 표준 평가
- **예시**: 알토스 / 본엔젤스 / 매쉬업

→ CVC 미팅에는 "모회사 시너지" 슬라이드 1장 추가 필수.

## 8. 한국 VC 미팅 전 준비 체크리스트

### 1주일 전
- [ ] 미팅 잡힌 VC 3년치 투자 포트폴리오 조사
- [ ] 그 VC가 최근 트윗·블로그·인터뷰에서 자주 쓰는 단어 추출
- [ ] 그 VC가 거절한 우리 카테고리 회사 있는지 확인

### 3일 전
- [ ] 덱을 그 VC 화법에 맞춰 30% 수정
- [ ] 그 VC 대표 이력 확인 (LinkedIn / The VC)
- [ ] 공통 지인 1명 reference 가능한지 확인

### 1일 전
- [ ] 덱 PDF 변환 + 폰트 임베드 확인
- [ ] 5분 / 10분 / 15분 스크립트 3종 준비
- [ ] Q&A Top 20 답변 암기

### 미팅 후 24시간 안
- [ ] 감사 메일 (받은 질문 1개에 추가 답변 포함)
- [ ] 미팅에서 받은 새 질문 → 백업 슬라이드 강화
- [ ] 후속 미팅 가능성 정중 확인

## 9. 거절 메시지 해석법

VC 거절 메일은 진실을 안 알려준다. 진짜 의미 해석:

| 표면 메시지 | 진짜 의미 |
|---|---|
| "지금 시기가 맞지 않습니다" | 트랙션 부족 |
| "포트폴리오 fit이 안 맞습니다" | 우리 카테고리 패스 |
| "조금 더 진척 후 다시" | "이번엔 NO, 6개월 후 보자" |
| "Lead 잡히면 같이 보겠습니다" | "다른 VC 결정 따라가겠다" |
| "팀이 좋네요, 다음에" | 팀은 OK, 시장이 작거나 트랙션 부족 |
| "기술이 인상적입니다" | "기술만 좋고 비즈니스 약함" |

→ 거절 받으면 그 VC의 진짜 이유를 추정해서 다음 미팅에 보강.

## 10. SSGI 정부 경진대회 → VC 자료 변환 가이드

현재 SSGI 덱은 서울시 빅데이터 경진대회용. VC 자료로 변환 시:

### 추가 슬라이드 (5장)
1. **Why Now** — GPT-4o + 카카오 알림톡 + 정부 1,500억 unlock
2. **Product 데모 화면** — 실제 캡처 + QR (영상 링크)
3. **GTM** — 첫 100 → 1,000 → 10,000 채널 전략
4. **Team** — 4인 + "이 문제와 연결" 스토리
5. **Ask** — Pre-A 5억 / 18개월 / 인건비 60% + GTM 25% + R&D 15%

### 삭제 슬라이드 (3장)
1. **목차** (VC는 안 봄)
2. **ESG 5점 매칭** (VC는 ESG 거의 안 봄, 1줄로 압축)
3. **Backup 자체 채점** (VC는 자체 채점 안 믿음)

### 수정 슬라이드 (3장)
1. **Cover** → "Pre-A 5억 모집" 라운드 명시
2. **Roadmap** → 마일스톤 ↔ ARR/MAU 매핑 추가
3. **Closing** → "한 명이라도 살리면" 유지 + Lead 의향 표시

→ VC 모드 덱은 약 18장 (현재 22장에서 -3 + 5)

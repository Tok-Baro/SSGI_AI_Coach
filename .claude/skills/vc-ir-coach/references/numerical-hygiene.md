# 숫자 위생 — TAM·트랙션·재무 정직성

> VC가 가장 빠르게 NO 결정하는 신호 = **숫자 거짓말**.
> "큰 숫자 보여주려다 신뢰를 잃는다." 작은 숫자 + 정직 표기가 항상 이긴다.

---

## 1. TAM/SAM/SOM 검증 룰

### Top-down은 즉시 NO

❌ **금지 패턴**
- "한국 자영업 시장 100조 규모"
- "글로벌 SaaS 시장 5조 달러"
- "Statista에 따르면 X 시장은 연 15% 성장"

→ VC가 다 본 자료. 본인이 산식 못 만들면 "시장 모르는 사람" 신호.

### Bottom-up 강제 변환

✅ **올바른 패턴**
```
TAM = 모집단 × 진입율 × 단가 × 빈도

예시 1: SSGI AI 경영코치
730만 사장님 (행안부 통계)
× 30% 디지털 수용 (한국 모바일 SaaS 산업 평균)
× 9,900원/월 (베타 인터뷰 N=8 결제 의향 단가)
× 12개월
= 2,604억원/년
```

각 변수마다 **출처** 명시 의무. 출처 없으면 "추정"으로 표기.

### SAM 산식 — 진입 가능 시장
```
SAM = TAM × (지역 / 언어 / 규제 / 채널) 한정 비율

예: 서울 한정 = 65만 사장님 (국세청 사업자등록)
     65만 / 730만 = 8.9%
     SAM = 2,604억 × 8.9% = 232억/년
```

### SOM 산식 — 3년 목표
```
SOM = SAM × 시장 점유율 가설

예: 5,000 MAU × 10% Pro 전환 = 500 Pro
     500 × 9,900원 × 12 = 5,940만원/년
     → SAM 232억 대비 0.025% 점유 (Year 3)
```

→ SOM이 SAM의 0.01~0.1% 이내가 정상. 5%+ 잡으면 "무모"한 신호.

### 민감도 분석 (선택)
TAM·SAM·SOM 가정 변수 하나가 ±20% 변할 때 결과 변동 표기.
9/10점 받으려면 필수.

## 2. LTV / CAC — Pre-revenue 표기법

### 환각 패턴 (즉시 정정)

❌ "LTV/CAC 3.96, Payback 4.8개월"
→ 결제 데이터 0건이면 산출 불가능. VC는 30초 안에 적발.

❌ "예상 LTV 240,000원"
→ "예상"이라는 단어로 책임 회피 시도. VC는 안 믿음.

### 정직 패턴

✅ **결제 데이터 없을 때**
```
LTV/CAC: N/A (결제 모듈 2026 Q3 출시 예정)

베타 가설:
- 9,900원/월 × 18개월 평균 (가설) = 178,200원
- CAC: 카카오 알림톡 25원/건 × 50회 = 1,250원
- 가설 LTV/CAC: 142x (단, churn 가정 0%인 상한)
- 정상화 (월 churn 5% 가정): LTV = 178,200 × (1-0.95^18) = 약 110,000원

* 모두 가설, Year 2 코호트 데이터로 검증 후 갱신
```

✅ **결제 의향만 있을 때**
```
인터뷰 N=8 중 5명 9,900원 결제 의향 표명 (62.5%)
* 의향 ≠ 실 결제. 결제 모듈 출시 후 코호트 측정 예정
```

### Acceptable Pre-Seed 트랙션

VC가 Pre-Seed에서 트랙션 0이어도 OK인 신호:
- 인터뷰 N≥10 + 정성 인용 3건+
- 베타 등록자 ≥ 100
- 핵심 기능 라이브 데모 가능
- 파일럿 MOU 의향 1건+

## 3. 핵심 메트릭 사전 (한국·영문)

| 지표 | 영문 | 정의 | Pre-A 합격선 | Series A 합격선 |
|---|---|---|---|---|
| 월간 활성 | MAU | Monthly Active Users | 1,000+ | 10,000+ |
| 일간 활성 | DAU | Daily Active Users | 100+ | 1,000+ |
| 7일 retention | D7 | 가입 후 7일 차 재방문율 | 25%+ | 35%+ |
| 30일 retention | D30 | 가입 후 30일 차 재방문율 | 15%+ | 25%+ |
| 이탈률 | Churn | 월간 이탈 비율 | 10%↓ | 5%↓ |
| 연간 매출 | ARR | Annual Recurring Revenue | 1억+ | 3억+ |
| 월 매출 | MRR | Monthly Recurring Revenue | 800만+ | 2,500만+ |
| 매출 성장률 | Growth Rate | 월별 % 성장 | 10%+ MoM | 20%+ MoM |
| 순매출 유지율 | NRR | Net Revenue Retention | 100%+ | 110%+ |
| 평균 결제액 | ARPU | Average Revenue Per User | 9,900원~ | 19,800원~ |
| 회수 기간 | Payback | CAC 회수까지 개월 | 12개월↓ | 6개월↓ |
| 매직넘버 | Magic Number | 신규 ARR / S&M | 0.7+ | 1.0+ |
| 소진율 | Burn | 월별 cash 소진 | — | — |
| 잔여 기간 | Runway | cash / burn = 개월 | 18개월+ | 18개월+ |
| 소진배수 | Burn Multiple | Net Burn / Net New ARR | 1.5↓ | 1.0↓ |

→ Pre-A 자료에 NRR / Burn Multiple 같은 단어 쓰면 "고급 IR" 신호. 단, 정의 정확히 알 때만.

## 4. 트랙션 차트 — 무엇을 보여줄까

### 보여주면 NO 트리거
- ❌ 누적 가입자 (vanity metric)
- ❌ 누적 다운로드
- ❌ "총 페이지뷰 1억"
- ❌ 단일 시점 메트릭만

### 보여주면 YES 트리거
- ✅ 월별 MAU 6개월 차트
- ✅ 코호트 retention (가입월별 D7/D30)
- ✅ ARR 월별 누적
- ✅ NPS / CSAT 추세
- ✅ 결제 전환 funnel (방문 → 가입 → 결제)

### 차트 그릴 때 룰
- Y축 0부터 시작 (왜곡 금지)
- 비교 구간 명확 (전월/전분기/전년)
- 데이터 포인트에 출처 (자체 / Google Analytics / Mixpanel)
- "AI 추정" amber chip (시뮬 데이터)

## 5. 환각 숫자 적발 체크리스트

리뷰 시 다음 패턴 발견하면 즉시 검증:

### 패턴 1: 둥근 숫자만
- "1,000명 가입" / "100만 매출" → 실제는 985명, 970,000원일 텐데?
- 정상: "987명 가입 / 970,400원 매출"

### 패턴 2: % 만 있고 분모 없음
- "재구매율 80%" → N=10에서 8명일 수도
- 정상: "재구매율 80% (N=200, 4개월 코호트)"

### 패턴 3: 평균만 (분포 없음)
- "평균 객단가 1.5만원" → median 8천일 수도
- 정상: "평균 1.5만 / median 1.2만 / 75th 2.8만"

### 패턴 4: 미래 시제 + 강한 단정
- "월 매출 1,200만원 예상" → 근거 없음
- 정상: "Year 2 목표 월 매출 1,200만원 (가설, N=8 의향 데이터)"

### 패턴 5: top-down × top-down
- "전체 시장 5조 × 시장 점유율 5% = 2,500억"
- → bottom-up으로 강제 변환

### 패턴 6: 분모 일관성 없음
- 슬라이드 A: 730만 자영업
- 슬라이드 B: 480만 사업자
- 슬라이드 C: 65만 서울
- → 같은 모집단 정의 일관성 필요

### 패턴 7: 출처 없는 학술 인용
- "Lewis 2020에 따르면" / "Beck 2023" → DOI 검증 필요
- 정상: 검증 가능한 인용만 (Tversky·Kahneman 1981, Cialdini 2006 등)

## 6. 정부 경진대회 vs VC 자료 차이

### 정부 경진대회
- ESG 정량 (탄소 절감 tCO2eq) 필수
- 사회적 가치 (폐업 방지 N명 등) 강조
- 정부 지원금 사용계획 상세
- 평가표 매칭 chip 권장

### VC 자료
- ARR / MAU / Burn / Runway 핵심
- ESG는 1-line 정도
- 사용처는 인건비/GTM/R&D 분배
- 다음 라운드 트리거 명시

→ 한 덱으로 둘 다 잡으려면 **모듈러** (공통 본문 + 평가/Ask 분기)

## 8. 결제 모듈 출시 전 합법적 트랙션 표기

결제 0건일 때 보여줄 수 있는 트랙션:

### Tier 1 — 가장 강한 신호
- 인터뷰 N≥10 + 결제 의향 표명 ≥50%
- 베타 등록 ≥100명
- 파일럿 MOU 의향 1건+ (서울시 / 자치구 / 소진공)

### Tier 2 — 중간 신호
- Waiting list ≥500명
- 카카오 채널 친구 ≥1,000
- 미디어 노출 1~3건

### Tier 3 — 약한 신호 (보여주지 말 것)
- 누적 페이지뷰
- 누적 다운로드
- "관심 표명" (정량 없는)

→ Tier 1만 슬라이드. Tier 2는 백업. Tier 3는 빼라.

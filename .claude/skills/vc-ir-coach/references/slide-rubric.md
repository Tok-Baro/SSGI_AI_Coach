# 슬라이드 채점표 — 15 Essential Slides

> 시드~Pre-A 기준. 각 슬라이드 0~10점, 총 100점 + 나머지 5장 (가산점).
> **70점 미만 = 1차 미팅·데모데이 통과 어려움**.

---

## 채점 룰

각 슬라이드:
- **0~3** = 즉시 NO 신호 (환각/일반론/누락)
- **4~6** = 평균 (정보는 있으나 임팩트 약함)
- **7~8** = 좋음 (VC가 멈춰서 봄)
- **9~10** = 탁월 (다음 미팅 잡는 트리거)

---

## 1. Cover (표지) — 10점 만점

### Must Answer
"이 회사 한 줄로 뭐 하는 곳인가?"

### 0~3점 신호
- 슬로건만 있음 ("미래를 그리다")
- 회사 로고만 큼
- 한 줄 가치 제안 없음
- 팀명·연락처만

### 7~8점 패턴
- 회사명 + 한 줄 설명 (15자 이내)
- 카테고리 명확 ("B2B SaaS", "소상공인 AI 코치")
- 큰 숫자 1개 ("4,500개 가게 사용 중")

### 9~10점 패턴
- 한 문장으로 전체 비즈니스 요약
- "We're [X] for [Y] doing [Z]" 미국식 또는 한국형 변형
- 제출일·라운드·금액 (Pre-A 5억 모집 등)

### 예시 (Bad → Good)
- ❌ "SSGI · 데이터로 미래를 그리다"
- ✅ "SSGI · 사장님이 매일 받는 1줄 처방 — 서울 공공데이터 기반 AI 경영코치"

---

## 2. Problem (문제) — 10점

### Must Answer
"누가 / 얼마짜리 / 왜 / 지금 손해 보고 있나?"

### 0~3점 신호
- "X 시장은 비효율적입니다" (일반론)
- 통계 1개로 5번 반복
- 페르소나 없음

### 7~8점 패턴
- 페르소나 1명 발화 인용
- 정량 손실 1개 (얼마 / 몇 명 / 몇 년)
- 외부 통계 출처 1개

### 9~10점 패턴
- 페르소나 + 인용 + 정량 + 출처가 한 슬라이드에
- "왜 지금 풀어야 하나" 시점성 신호
- 이 문제가 얼마나 깊은지 본인이 겪어봤다는 신호

### SSGI 적용 (현재 덱 Slide 03)
- 4.5년 vs 9.8년 + 53.7% + 240만원 = ✅ 정량 4개 + 출처
- 비대칭 3가지 카드 = ✅ 패턴 명확
- 8/10점

---

## 3. Solution (솔루션) — 10점

### Must Answer
"그래서 어떻게 푸나? (한 문장)"

### 0~3점 신호
- 기능 8개 나열
- 화면 캡처 5장
- 기술 스택 자랑 ("GPT-4o + LangChain + ChromaDB...")

### 7~8점 패턴
- 한 줄 솔루션 + 데모 화면 1장
- "어떤 입력 → 어떤 출력" 명확
- 기존 풀이법과 차이 1줄

### 9~10점 패턴
- "10초 데모" 같은 시각적 한 컷
- Before/After 대비
- 솔루션이 문제 슬라이드의 모든 정량 손실을 직접 푼다는 매핑

### SSGI 적용 (현재 덱 Slide 06)
- 3-tier 신뢰 계층 다이어그램 = ✅ 명확
- 데모 화면 부재 = ❌ (실제 스크린샷 추가 권장)
- 7/10점

---

## 4. Why Now (시점) — 10점

### Must Answer
"5년 전엔 안 됐는데 지금 되는 이유?"

### 0~3점 신호
- 슬라이드 자체 누락 (가장 흔한 NO 트리거)
- "AI가 발전했습니다" (너무 일반적)
- "코로나 이후 변화" (2026년에 안 통함)

### 7~8점 패턴
- 3개 unlock 명시 (정책·기술·인구·인프라 중 3가지)
- 각 unlock에 정량 데이터

### 9~10점 패턴
- "5년 전과 지금" 비교 표
- 시점성을 놓치면 누가 가져갈지 명시

### Unlock 후보 (한국 시장 2026 기준)
- GPT-4o / Claude 4 — RAG 비용 90% 인하
- 카카오 알림톡 채널 정식 개방
- 정부 마이데이터 스코프 확장
- 서울시 빅데이터캠퍼스 데이터 무료 개방
- 소상공인 디지털 전환 정부예산 1,500억 (2026)
- 65세+ 스마트폰 보급률 90%+

### SSGI 적용
- 현재 덱에 Why Now 명시 슬라이드 ❌
- 권장: Slide 04 직전에 1장 추가
- 0/10점 → 슬라이드 추가 시 8/10 가능

## 5. Product (제품) — 10점

### Must Answer
"실제로 작동하는 모습 1장"

### 0~3점 신호
- 와이어프레임만
- 시스템 구조도 (engineering 화면)
- 글자 가득한 mock-up

### 7~8점 패턴
- 진짜 화면 캡처 1~2장
- 핵심 인터랙션 명시 (가입 → 첫 액션 = 30초)
- 데모 영상 QR 코드

### 9~10점 패턴
- 실제 사용자가 받은 메시지 캡처 (개인정보 가림)
- 라이브 데모 가능 표시
- "지금 시연 가능" 멘트

### SSGI 적용 (현재 덱 Slide 10)
- 4 화면 카드 = 텍스트 위주 ❌
- 실제 캡처 추가 권장
- 6/10점

## 6. Market (TAM/SAM/SOM) — 10점

### Must Answer
"bottom-up 산식 한 줄"

### 0~3점 신호
- "X조 시장" top-down
- "한국 X 시장 규모 자료" 인용만
- TAM = 전체 인구 × 100% (말 안 되는 가정)

### 7~8점 패턴
- TAM bottom-up 산식 명시
- SAM = 진입 가능 시장 (지역·규제·언어 한정)
- SOM = 3년 목표 (실측 기반)

### 9~10점 패턴
- TAM/SAM/SOM 각각 산식 + 출처
- "이 가정이 틀리면 어떻게 되나" 민감도 분석
- VC가 본 다른 deck 비교 가능한 단가/빈도

### 산식 패턴
```
TAM = 모집단 × 진입율 × ARPU × 12
  예: 730만 사장님 × 30% 디지털 수용 × 9,900원 × 12 = 2,604억/년

SAM = TAM × 지역/언어 비율
  예: 2,604억 × (서울 사장 65만 / 전국 730만) = 232억/년

SOM = 3년 목표 코호트
  예: 5,000 MAU × 10% Pro × 9,900원 × 12 = 5,940만/년
```

### SSGI 적용 (현재 덱 Slide 15)
- TAM 2,604억 bottom-up = ✅
- SAM 232억 = ✅
- SOM 5,940만 = ✅
- 가설 라벨 = ✅
- 9/10점

## 7. Business Model (수익 모델) — 10점

### Must Answer
"단가 × 빈도 = ARPU. 누가 결제하나?"

### 0~3점 신호
- "Free + Pro + Enterprise" 표만
- 가격 미정
- 결제 데이터 0건인데 LTV/CAC 자랑

### 7~8점 패턴
- 단가 + 빈도 + 결제자 명확
- 타 플랫폼 단가 비교 (배민·당근비즈)
- 무료 → 유료 전환 가설

### 9~10점 패턴
- 베타 결제 의향 N건 정직 표기
- 결제 출시 일자 명시
- 수익 다각화 1~2개 (광고·데이터·B2B 라이센스)

### SSGI 적용 (현재 덱 Slide 16)
- Free/Pro/ENT 카드 + 가설 라벨 = ✅
- 결제 데이터 0건 정직 = ✅
- 8/10점

---

## 8. Traction (트랙션) — 10점

### Must Answer
"지난 N개월 추세 + 핵심 1지표"

### 0~3점 신호
- 누적 가입 자랑 ("1만명 돌파!")
- 비공개 메트릭만 ("높은 만족도")
- 차트 없이 텍스트만

### 7~8점 패턴
- 코호트 차트 1개
- 핵심 지표 1개 + 추세 (월별 6개월)
- 매출 / Active / Retention 중 가장 강한 1개

### 9~10점 패턴
- D7/D30 retention + 월 성장률
- NPS / 결제 의향 정성 1건
- 주요 고객사 로고 (B2B) or 사용자 발화 (B2C)

### Pre-revenue 트랙션 표기
- 결제 0건이면 "결제 모듈 Q3 출시 예정"
- 인터뷰 N=8 → "5/8 결제 의향" 정량
- 베타 시뮬 retention은 "시뮬 라벨" 명시

### SSGI 적용 (현재 덱 Slide 14)
- N=8 / 5건 결제 의향 / 0건 정직 = ✅
- 사장님 발화 인용 3건 = ✅
- 9/10점

---

## 9. Competition (경쟁) — 10점

### Must Answer
"우리만 가진 1가지"

### 0~3점 신호
- 4-quadrant 매트릭스 우상단 자뻑
- 경쟁사 1~2개만 (시장 모르는 신호)
- "우리는 다릅니다" 일반론

### 7~8점 패턴
- 5~7개 차원 표 + 경쟁사 3~5개
- 우리가 약한 1개 정직 노출
- "왜 다른 회사가 못 하나" 1줄

### 9~10점 패턴
- 차원별 정량 비교
- 모방 시 시간/비용 분석
- 진입장벽 (regulatory / data / network effect)

### 매트릭스 vs 표 선택
- 매트릭스: 차원 2개 + 회사 5~10개일 때
- 표: 차원 5~10개 + 회사 3~5개일 때 (Pre-A는 표 권장)

### SSGI 적용 (현재 덱 Slide 18)
- 6 차원 표 + 우리/기존 비교 = ✅
- 우리가 약한 1개 노출 ❌ → 추가 권장
- 7/10점

## 10. GTM (Go-to-Market) — 10점

### Must Answer
"첫 100명 / 첫 1,000명 어떻게 잡나?"

### 0~3점 신호
- "마케팅 강화" / "SNS 활용"
- "퍼포먼스 마케팅 진행"
- 채널 7개 동시 추진

### 7~8점 패턴
- 채널 1~2개 단단하게 + CAC 가정
- 첫 100명 → 1,000명 → 10,000명 단계 명시
- 파트너십 1~2개

### 9~10점 패턴
- LTV/CAC 가정 + payback 가정
- 채널별 ROI 가정 + 검증 일자
- referral / virality coefficient 1개

### SSGI 적용
- 현재 덱에 GTM 슬라이드 부재 ❌
- 권장: Slide 17 (Roadmap) 옆에 1장 추가
- 0/10점 → 슬라이드 추가 시 7/10 가능

## 11. Team (팀) — 10점

### Must Answer
"왜 이 팀이 이 문제를 끝까지 풀까?"

### 0~3점 신호
- LinkedIn 사진 + 직함만
- "Stanford / Google / Facebook" 만
- 풀타임 신호 부재

### 7~8점 패턴
- 각 멤버 + "이 문제와의 연결" 한 줄
- 풀타임 vs 파트타임 표시
- 핵심 채용 1~2명 명시

### 9~10점 패턴
- 창업자 본인이 이 문제를 겪었다는 스토리
- 자문위원 1~2명 (도메인 권위자)
- "이 팀 외에 못 푸는 이유" 1줄

### 한국 정부 경진대회 주의
- **개인정보 기재 금지** 공고 빈번 (서울시 빅데이터 등)
- → 팀명만 + 역할만 표기, 실명 ❌
- VC 미팅 시는 별도 팀 슬라이드 동봉

### SSGI 적용
- 현재 덱: 정부 경진대회 모드라 팀 슬라이드 부재 ✅ 정상
- VC 미팅 시는 별도 팀 슬라이드 1장 추가 필요

## 12. Roadmap (로드맵) — 10점

### Must Answer
"다음 6개월 마일스톤 3개"

### 0~3점 신호
- 5년 비전 (Pre-Seed / Pre-A에선 NO)
- "지속 성장" / "글로벌 진출"
- 정량 마일스톤 부재

### 7~8점 패턴
- 4 분기 × 3 마일스톤
- 각 분기에 핵심 메트릭 목표
- 다음 라운드 트리거 명시

### 9~10점 패턴
- 6개월 마일스톤이 시간순으로 명확
- 각 마일스톤이 이전 마일스톤에 의존
- "이 마일스톤 달성 못하면 어떻게 되나" 솔직

### SSGI 적용 (현재 덱 Slide 17)
- 4 분기 × 4 마일스톤 = ✅
- 카카오 4분기 마일스톤 명시 = ✅
- 8/10점

## 13. Financials (재무) — 10점

### Must Answer
"burn / runway / 다음 라운드 트리거"

### 0~3점 신호
- 5년 P&L 표 (예언 수준)
- EBITDA만 (핵심 메트릭 X)
- burn rate 누락

### 7~8점 패턴
- 월 burn + 현재 cash + runway 개월
- 다음 라운드 시점 + 예상 메트릭
- 채용 계획 (cost driver)

### 9~10점 패턴
- 시나리오 3개 (best/base/worst) + 각 runway
- 핵심 메트릭 (ARR / MAU)에 burn 매핑
- "이 burn으로 이 메트릭 달성 가능" 정합성

### Pre-Seed / 정부 경진대회 모드
- Financials 슬라이드 보통 제외 OK
- 대신 "지원금 사용계획" (정부 모드)

### SSGI 적용
- 현재 덱에 Financials 부재 ✅ (정부 경진대회 모드)
- VC 모드 변환 시 1장 추가 필수

## 14. Ask (요청) — 10점

### Must Answer
"얼마 / 무엇에 / 언제까지"

### 0~3점 신호
- Ask 슬라이드 누락 (가장 흔한 실수)
- "투자해 주세요" 일반론
- 사용처 미정

### 7~8점 패턴
- "X억원 / 18개월 runway / 채용 N + GTM Y"
- 다음 라운드 트리거 명시
- 공동투자자 모집 단계

### 9~10점 패턴
- Ask 분배 차트 (인건비 50% / GTM 30% / R&D 20%)
- 마일스톤별 cash trigger
- Lead investor 의향 표시

### SSGI 적용
- 현재 덱: 정부 경진대회라 Ask 슬라이드 부재 ✅
- VC 모드: Pre-A 5억 / 18개월 / AI 엔지니어 2 + GTM 1 추가 필수

## 15. Closing / Why Us (왜 우리를 선택해야 하나) — 10점

### Must Answer
"VC가 다음 미팅 잡는 단 하나의 이유"

### 0~3점 신호
- "감사합니다" 슬라이드만
- 연락처만
- 전체 요약 다시

### 7~8점 패턴
- 한 줄 핵심 가치 다시
- 감정·논리·행동 1개씩
- 다음 단계 CTA

### 9~10점 패턴
- "한 명이라도 살리면" 같은 정성 강한 클로징
- 비전 + 시간성 ("3년 안에")
- 청중에게 던지는 질문 1개

### SSGI 적용 (현재 덱 Slide 20)
- "한 명이라도 살리면" 정성 클로징 = ✅
- "추천 대신 놓치고 있어요" 핵심 가치 = ✅
- 9/10점

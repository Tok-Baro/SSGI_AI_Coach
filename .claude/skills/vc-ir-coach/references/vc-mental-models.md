# VC 멘탈 모델 — 투자자가 IR 덱을 읽는 방식

> 평균 시드 VC는 한 주에 100~200개 덱을 받는다. 한 덱에 쓰는 시간 평균 **3분 44초** (DocSend 2023).
> 깊이 읽는 시간 = **0**. 모든 슬라이드는 "다음 슬라이드를 볼 가치"를 만들어야 한다.

---

## 1. 3 단계 시간 테스트

### 5초 테스트 (표지 + 첫 1장)
- VC가 메일 클릭하고 PDF 첫 화면 보는 시간
- **무엇 + 누구 + 한 줄 가치**가 동시 보여야 함
- 통과 기준: "더 보고 싶다"는 호기심 발생

### 30초 테스트 (스크롤 슥)
- 표지 → 문제 → 솔루션 → 트랙션 → 시장 → Ask 까지 빠르게 훑음
- VC가 "1차 NO"를 결정하는 구간
- 통과 기준: 6 핵심 질문 (무엇/누구/왜지금/얼마/어떻게/누가) 답변 가능

### 3분 테스트 (한 번 정독)
- VC가 "1차 미팅 잡을지" 결정
- 모든 슬라이드의 헤드라인 + 큰 숫자만 봐도 스토리 흐름 명확
- 통과 기준: 다음 미팅 메일 수신

## 2. VC 의사결정 트리 (시드~Pre-A 기준)

```
받은 IR 덱
    │
    ▼
[5초] 표지에서 "이게 뭔지" 알 수 있나?
    NO → 휴지통
    YES ↓
    │
[30초] 문제·시장이 충분히 큰가?
    NO → 정중한 거절 메일
    YES ↓
    │
[3분] 트랙션 / 팀 / 차별화 신호 1개 이상?
    NO → "조금 더 진척 후 다시"
    YES ↓
    │
[1차 미팅 30분]
    │
    ├─ 팀 fit 확인
    ├─ 시장 가설 검증 (VC가 만난 다른 케이스 비교)
    ├─ 다음 6개월 마일스톤 명확성
    │
    └─ DD 진입 결정 (보통 2~5%)
```

**시사점**: IR 덱의 90% 임무는 "**1차 미팅 잡기**"에 있다. 모든 디테일은 미팅에서. 덱은 트레일러.

## 3. 스테이지별 기대치 (한국 시장 기준)

### Pre-Seed / Seed (티켓 1~5억)
- 트랙션: PoC 정도면 OK. 인터뷰 N=10~20도 OK.
- 팀: **창업자 → 문제와의 연결**이 가장 중요
- 시장: TAM bottom-up 한 줄이면 충분
- 결제: 의향 표명 5~10건이면 합격선
- 핵심 질문: "이 사람 이 문제 끝까지 풀까?"

### Pre-A (티켓 5~20억)
- 트랙션: MAU 1,000+ / 결제 10건 이상 / 코호트 3개월+
- 팀: 풀타임 3~5명, 도메인 전문성 명시
- 시장: SAM 명확 + SOM 3년 목표 정량화
- 결제: 가설 단계 OK이나 "결제 출시 일자" 명시
- 핵심 질문: "이게 정말 시장이 있나?"

### Series A (티켓 20~100억)
- 트랙션: ARR 3억+ / D30 retention 25%+ / 코호트 6개월
- 팀: VP 급 1~2명 채용 완료
- 시장: 월 성장률 10~20% 6개월 연속
- 결제: PMF 신호 (NRR 110%+ / Net New Logos 가속)
- 핵심 질문: "10x 성장 가능한가?"

→ **스테이지 잘못 잡으면 즉시 NO**. Pre-Seed인데 Series A 자료 만들면 "수치 부풀린 사기꾼"으로 보임.

## 4. VC가 매번 던지는 5 질문 (Why X 시리즈)

### Why this market?
- 시장이 충분히 큰가 (bottom-up)
- 시장이 빠르게 자라는가
- 시장의 변곡점이 있는가 (정책·기술·인구)

### Why now?
- 5년 전엔 왜 안 됐나
- 5년 후엔 왜 늦나
- 어떤 unlock이 일어났나 (GPT 출시 / 카카오 알림톡 정책 변화 / 정부 지원사업 확대)

### Why this solution?
- 다른 풀이법은 왜 안 되나
- 우리만의 unfair advantage는
- 1년 뒤 모방되면 어떻게 되나

### Why this team?
- 창업자가 이 문제와 연결되는 이유
- 도메인 + 기술 + 영업의 3각 균형
- 풀타임 헌신 신호

### Why now (this round)?
- 왜 지금 이 금액이 필요한가
- 18개월 burn / runway 산출 명확
- 다음 라운드 트리거 (ARR X억 / MAU Y만)

→ 이 5 질문에 슬라이드별로 1개씩 답이 매핑되어야 함. 답 안 되는 슬라이드는 삭제.

## 5. VC 거절 시그널 (피해야 할 적)

### 즉시 NO 발동 단어 (Buzzword Black List)
- "혁신적인" / "혁신을 일으키는"
- "데이터 드리븐" (트랙션 없는 회사가 자주 씀)
- "AI 기반" (구체 기술 없을 때)
- "글로벌 진출 예정" (한국도 못 잡았으면서)
- "블록체인" / "메타버스" (2026 기준)
- "Disruptive" (영문 덱에서 특히)
- "First mover" (보통 거짓말)
- "Conservative estimate" (TAM 부풀리기 신호)

### 즉시 NO 발동 패턴
- 표지에 작품명만 크게 (회사 무엇인지 모름)
- 문제 슬라이드 5장 (한 장이면 끝)
- 솔루션 슬라이드 기능 8개 나열
- 시장 슬라이드 "X조 시장" (top-down)
- 경쟁 4-quadrant 자뻑
- 팀 슬라이드 LinkedIn 사진+직함만
- 5년 비전 (Pre-Seed 단계)
- Ask 슬라이드 없음

### 신뢰 가는 신호 (VC가 추가 미팅 잡는 신호)
- 표지가 30초 안에 이해됨
- 문제 슬라이드에 페르소나 1명 발화 인용 (실명 OK)
- TAM bottom-up 산식 + 출처
- 트랙션 코호트 차트 (가입 ❌, retention ✅)
- 팀 슬라이드에 "왜 이 문제냐" 한 줄 (스토리)
- Ask 슬라이드에 "X억 / 18개월 / 채용 N명 + GTM Y" 정량
- 백업 슬라이드 10~15장 (질문 대비)

## 6. 데모데이 vs 1:1 미팅 차이

### 데모데이 (TIPS / K-Startup / 카카오벤처스 / 본엔젤스 데모데이)
- 5~10분 발표 + 5분 Q&A
- 슬라이드 10~15장 권장 (30~45초/장)
- 청중 다수 (50~200명) — 한 명이 아니라 "여러 명에게 동시"
- 카메라 의식 — 시각 슬라이드 비중 ↑
- 정량 평가 (Government은 평가표 매칭)
- 핵심: **표지 + 마지막 한 줄**이 가장 기억된다 (peak-end rule)

### 1:1 VC 미팅
- 30~60분
- 슬라이드 20~30장 + 백업 10장
- 깊은 대화 — 한 슬라이드에 5분 머물 수도
- 정성 평가 (chemistry · trust)
- 핵심: **VC 화법 매칭** (그 VC가 자주 쓰는 단어 사용)

→ 같은 회사라도 두 덱은 **다르게** 만들어야 한다. 데모데이 덱을 그대로 1:1에 쓰면 깊이 부족, 반대도 같음.

## 7. 정부 경진대회 / 사업화 트랙 차이

### 평가표 매칭이 절대 우선
- 서울시 빅데이터: 공공25·AI20·독창15·완성15·발전20·ESG5
- TIPS: 기술성·시장성·사업성·팀·자금사용계획
- K-Startup: 사업성·성장성·시장성

→ 슬라이드 우상단에 **평가 항목 매칭 chip** 노출 권장 (심사위원 친화)

### VC 덱과 정부 덱의 차이
| 차원 | VC 덱 | 정부 덱 |
|---|---|---|
| 톤 | 도전적, 큰 비전 | 안정성, 정책 기여 |
| ESG | 거의 없음 | 필수 (5~10점 배점) |
| 정량 | 트랙션 중심 | 사회·경제 임팩트 |
| 팀 | "We're crazy enough" | "공신력 있는 팀" |
| 지원금 | 보통 명시 안 함 | 상세 사용계획 의무 |

→ 한 덱으로 둘 다 잡으려면 **모듈러 구조** (공통 본문 + 평가 매칭 chip 추가/제거)

## 8. VC가 절대 말 안 하는 진실

1. **체크인 전에 결정 끝남** — 미팅은 확인 절차
2. **Reference call이 가장 중요** — 동료 VC, 전 직장 동료에게 묻는 평판이 60%
3. **시장 사이즈 안 믿음** — 그냥 "큰 시장 좋아함" 표시
4. **트랙션 < 팀** (Pre-Seed) → **트랙션 = 팀** (Pre-A) → **트랙션 > 팀** (A+)
5. **다른 VC가 들어왔는지가 결정적** — Lead 잡으면 follower 줄섬
6. **거절 시 진짜 이유 안 알려줌** — "지금 시기가" / "포트폴리오 fit" 같은 형식 답변
7. **2번째 미팅까지 가면 50%** — 첫 미팅 나오는 데이터 기반

→ 이 진실을 알고 덱을 짜면 **첫 미팅까지 가는 게 95% 임무**임을 안다.
